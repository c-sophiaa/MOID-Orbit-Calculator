# MOID Orbit Calculator

A Java program for modeling orbital paths and determining the Minimum Orbit Intersection Distance (MOID) of a Near-Earth Object (NEO).

## Overview

This project explores orbital geometry and object-oriented programming through a Java-based calculator for analyzing Near-Earth Object orbits.

The program accepts information about a Near-Earth Object and uses orbital representations to support MOID determination. The project separates different orbital models into Java classes, demonstrating object-oriented design through inheritance and specialized orbit implementations.

## Tech Stack

- Java
- Object-Oriented Programming (OOP)
- Mathematical / orbital modeling

## Key Features

- Models orbital paths using Java classes
- Supports multiple orbital representations
- Performs calculations related to Minimum Orbit Intersection Distance (MOID)
- Accepts Near-Earth Object information through a command-line interface
- Uses object-oriented design to organize orbital calculations
